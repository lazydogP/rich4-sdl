Place a CJK TrueType/OpenType font here for the SDL_ttf text path.

Preferred filenames:

- rich4.ttf
- rich4.ttc
- MingLiU.ttf / MingLiU.ttc
- PMingLiU.ttf / PMingLiU.ttc
- SimSun.ttf / SimSun.ttc

All builds render Big5 UI text through SDL_ttf/FreeType. Miyoo packages include
`assets/fonts/rich4.ttc` together with the required runtime libraries. Use only
a font whose license permits redistribution.
