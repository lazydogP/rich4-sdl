# 卡片使用提示与地产目标表现（V3.11）

## 地址与目标模块

`0x441BAA` 是真人和 AI 的共同出牌入口；`0x441F73` 负责卡片提示。
平台无关的等待与继续执行位于 `src/app/card_use_flow.c`，SDL 负责资源读取和绘制。

## IDA 结论

2026-11-14 通过 IDA Pro MCP 复核 `Rich4.exe`，image base `0x400000`，SHA-256
`5a90aee28ee5f7a5c3ba5cb935c9e55751a529c25fcd91208748a66293569550`。

- 真人 `0x441CBC` 与 AI `0x441DEF` 均先调用 `0x441F73`，返回后才进入卡片 handler。
  标题格式为 `0x465305` 的“使用%s”。AI 不打开真人的卡槽选择窗口。
- `0x441FC6` 从 handle `0x48A0E4`（`Data.mkf`）读取 `card_id + 570`。
  原始卡 ID 1..30 对应 `Data.mkf[571..600]`，165×256 卡图从 `(138,200)` 绘制。
  提示背景取 `Data.mkf[517]` 的 chunk 5，标题中心 `(220,129)`。
- `0x44209E` 播放 sound ID 62；`0x4420AB` 经 `0x4528B9(1500)` 等待，随后恢复
  `(0,40)-(440,480)` 的背景。等待期间可以通过松键、左／右鼠标松开提前结束。
- `0x407AD2` 内的 `0x4080B2..0x4080D6` 从同一 `Data.mkf` handle 读取 396..415，
  写入 `0x496930[0..19]`。`0x40E6BB` 在 `a1=0` 时读取 `0x49697C`，即该表
  第 19 项：`Data.mkf[415]`，chunk 0。该指向目标的共享效果没有额外音效调用。
- `0x40E669` 先把起终点投影到当前视口。步数为
  `trunc(sqrt(dx*dx + dy*dy) / 8 + 1)`；`0x457DBC (__CHP)` 临时使用 x87 的截断
  舍入模式。位置使用 float 增量；每次显示至少等待 24 ms，结束再等待 100 ms。
  投影起终点相同时跳过飞行及尾部等待。
- 怪兽卡 `0x443917` 与拆除卡 `0x443B0F` 的地产分支依次为：施放者台词；AI 的共享
  目标效果；`0x41D476(x,y,0)` 聚焦地产；修改建筑并播放专用动画；等待 500 ms；
  地产原 owner 的受害者台词；`0x41D546` 返回当前角色。
- 怪兽／拆除分别使用 `Data.mkf[557] / [529]`，`Effect.mkf[80] / [97]`。
  `0x45144F` 的绘制原点均为 `(0,40)`；`0x450CED` 从 FLC header +16 读取帧间隔。
  packed flags 分别为 `0x100001 / 0x260001`，byte 2 的 16/38 是动画内部背景阶段
  的帧编号。`0x450DD7` 把 BYTE2(flags) 赋给全局刷新计数，`0x451183` 先增加已解码
  帧数，`0x4511FF/0x4512BF` 在相等时刷新地图并更换动画底图。因此零基帧号 15/37
  才开始显示破坏后的建筑状态，之前保留原 type/level。拆除动态对象不播放地产破坏 FLC。
- 两张卡的施放者台词指针分别位于 `0x481262 / 0x481266`，受害者台词分别位于
  `0x481352 / 0x481356`，角色步长均为 360 bytes；保留 Big5 文本、语音和图标前缀。

## 红卡／黑卡的台词和股票提示

2026-11-14 另经 IDA Pro MCP 复核 `0x444F25`、`0x44503F`、`0x440CAC`，模块及
SHA-256 与上文一致。

- 红卡 `0x444F5B`、黑卡 `0x445079` 均在真人／AI 分支前调用 `0x44EF41(player,0,text)`。
  台词指针分别为 `0x481296 / 0x48129A + character*360`；12 名角色的语音资源分别为
  `449+52*character` 和 `450+52*character`。Big5 台词及语音／图标前缀一并保留。
- 真人在台词返回后进入 `0x42B58F(1)`／`0x42B58F(2)`；取消选股不消费卡片。
- AI 通过 `0x41E6F2(0)` 取得预选股票，写入涨跌标志 `0x20 / 2`，再调用 `0x429040`
  更新该股票行情。AI 不进入股票选择窗口。
- AI 从选中股票记录取得名称，经 `0x452946` 压紧名称，使用 `0x4653AE` 的原始格式
  `對%s使用%s！`，在 `0x444FDB / 0x445154` 调用 `0x440CAC(text,1500)`。
  此提示仅绘制通用文字背景和文本，没有卡图或额外卡片音效。等待可由松键或左右鼠标
  松开提前结束；提示返回后原版继续卡片 handler 的收尾。
- SDL 的股票名称取当前地图的公共股票名称表，文字提示进入既有的
  `special_place_notice` 队列，共用 `0x440CAC` 的绘制、等待、输入中断与恢复路径。

`test_card_use_flow` 覆盖两张卡、12 名角色、语音等待、真人选股前台词，以及 AI 股票
提示的正常到期和提前跳过。`test_card_presentation` 覆盖真实 SDL 调度中的行情更新、
提示结束后恢复回合，并逐像素验证八张地图各 12 支股票的两种提示。

## 被动反制与其他主动卡

同一可执行文件的 `0x444691`、`0x44476A`、`0x444A60`、`0x444BB2` 通过
IDA Pro MCP 复核。卡图仍由 `0x441F73` 统一显示，台词仍由 `0x44EF41` 播放。

- 梦游 `0x4441DC` 和陷害 `0x4444BF` 先向原受害者累计 `150*物价指数` 的关系值，
  再检查免罪卡；免罪自动亮卡并播放使用者台词，阻止本次处罚。没有免罪才询问嫁祸。
- 嫁祸 `0x44476A`：真人先亮卡，有一名候选人时显示是否转嫁给该人的确认，有多名时
  使用 `Data.mkf[518]` 与 `Data.mkf[2]` 的头像选择器。拒绝或取消不消费嫁祸卡。
  AI 先按 `0x40D2D3` 的最大关系值选人，未选中时由 `0x40D31C` 随机选择合格角色；
  选人发生在金额门槛判断之前。攻击使用 mode 0，无金额门槛；查税使用 mode 2，
  需现金的 20% 大于 `4000*物价指数`。接受后播放施放者 type 0 和目标 type 2 台词。
  AI 亮卡后还用 `0x46536F` 的“嫁禍給%s！”通用提示等待 1500 ms。
- 免费 `0x444A60`：真人先确认是否使用，再亮卡和播放 type 0 台词；另一方非 -1 时
  接着播放其受害者 type 1 台词。AI 门槛为 `(rand()%3000+3000)*物价指数`，费用
  大于现金或门槛时接受。拒绝不消费免费卡，收费链继续检查嫁祸。
- 梦游的普通受害者在状态写入之前说 `0x48089E + character*108` 的 type 1 台词。
  陷害先完成 `0x43D593` 的入狱流程，再播放卡片表 role 2、type 1 台词。
  原受害者确实受罚且持有复仇卡时，才进入 `0x444691` 的亮卡、使用台词和反击；
  嫁祸后的受害者不再触发这次复仇。梦游反击不重复增加坏日数统计。
- 查税 `0x4451F0` 依次为施放者台词、AI 目标飞行、免费、嫁祸（原费用须大于 2000）、
  扣款、`0x4653C0` 的“抽取%s\n\n%d元稅金！”1500 ms 提示、受害者 type 2 台词。
  嫁祸后按新付款人的现金重新计算 20%。购地失败的现金提示位于 `0x46530C`。
- 卡片台词总表从 `0x48123A` 开始，布局为角色 12 × role 3 × 卡片 30，角色步长
  360 bytes。role 0 是使用台词，role 1 是对自己生效的台词，role 2 是受害者台词。
  改建台词在商业地类型选择之前，抢夺台词和目标效果在战利品选择之前；取消后者不消费卡。
- 换地 `0x442622`／换屋 `0x442B02` 根据两处地产的 owner 和 level 决定是否说话：
  当前角色取得不低于原来等级的建筑时说使用台词，受影响的另一 owner 说 type 2 台词。
  换地在 owner 交换后闪烁；换屋先闪烁，再调用 `0x40B4F8` 移动两栋建筑。
  该移动使用世界坐标距离的 `trunc(distance/16+1)` 步，每步至少 24 ms；结束恢复
  坐标、交换建筑 type/level、刷新并等待 500 ms。换地也有刷新后的 500 ms 等待。
- 天使 `0x4434C0` 对同名土地组处理：level 小于 5 的普通住宅升一级，非住宅建筑只
  从空地建成一级。普通住宅到五级时，闪烁结束后播放 `0x40B0CD` 的 `Data.mkf[523]`
  动画和 sound 90。商业地由 `0x40B110` 按 `0x474940={1,5,5,1,5}` 的类型上限升级，
  空地先选择建筑类型。恶魔 `0x4436E0` 对同名组同时清除 type 和 level，并按
  `30*原等级*物价指数` 累计关系值。
- 上述土地选择使用 `0x451985` 的 16 帧亮度序列：
  `4,8,12,16,12,8,4,0,-4,-8,-12,-16,-12,-8,-4,0`，每帧 30 ms，随后 400 ms。
  天使的住宅分支对真人也调用目标飞行；其他相应卡片只在 AI 分支调用。
- 送神 `0x444C45` 先处理炸弹／神明离开，再说使用台词。请神 `0x444E1A` 先说使用
  台词，临时隐藏原地图神明，再通过 `0x40E669(slot,神明坐标,角色坐标,0)` 飞向角色，
  最后进入原有神明获得流程。飞行图为该神明 `Data.mkf[395+type]`，chunk 为
  `(node_direction+8-map_direction)&7`，保持同一朝向，不附加标记飞行的 100 ms 尾部。
