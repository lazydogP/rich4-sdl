# 原版游戏文字与选择界面

依据：原版 `Rich4.exe` 的 IDA Pro MCP 输出，以及
`rich4/asm/rich4_card_hongka.asm`、`rich4_card_heika.asm`、
`rich4_ui_stock.asm` 和 `rich4/docs/target_selection.md`。
地址对应 V3.11 程序；字符串使用 Big5/CP950。

## 收款文案与参数

强盗抢卡在 `0x41C2CE` 使用 `0x463AF7` 的 `奪取%s%s！`。
两个参数依次为被抢者姓名与卡名。

关联收款地产在 `0x419D1A` 使用 `0x46399A`：

```text
%s

屬%s與%s

請付%d元%s
```

参数依次是地产名、两名收款者姓名、应付总金额、费用名称。
费用名称取自 `0x47517C`；保险收费使用其中的“保險費”。

公司建筑提示在 `0x463918` 使用 `餘股:%d`，参数是记录 `+0x30` 的剩余股份。
建筑提示的触发和内容见 [地图对象信息泡](417559-map-info-bubble.md)。

## 贷款到期流程

`0x436A5A` 按距离到期的天数分派：

| 剩余天数 | 原版行为 | 字符串或入口 |
|---:|---|---|
| 3 | 真人玩家进入银行面板 | `0x43695E` |
| 2 | 显示“距貸款到期日 / 還剩２天！” | `0x464B5C` |
| 1 | 显示“距貸款到期日 / 還剩１天！” | `0x464B43` |
| 0 | 显示“貸款到期日 / 強制執行！”，随后执行还款并清除贷款字段 | `0x464B2C`，调用 `0x436AA5` |

斜线表示两个换行；通知中的 `１/２` 是全角字符。三条固定通知显示 1500 ms。

## 红卡、黑卡的股票选择

红卡 handler `0x444F25` 在 `0x444FFA` 调用 `0x42B58F(1)`；
黑卡 handler `0x44503F` 在 `0x4450BE` 调用 `0x42B58F(2)`。
两者共用股票界面，入口从 `Panel.MKF[75]` 读取资源。

`0x42B58F` 的原版标题为“持有股數表”（`0x4640A6`）和
“股 價 表”（`0x4640B1`），并绘制股票名称、成交价、涨跌、交易量等列。
红卡、黑卡调用路径不额外绘制卡片专属的选股标题。
callback `0x42AAFF` 中的固定拒绝通知为“漲停無法買進！”（`0x464088`）
和“跌停無法賣出！”（`0x464097`）。

## 卡片、道具的地图目标选择

真人地图选择入口 `0x446AE8(mask)` 直接通过 `0x4018E7` 进入公共
callback `0x445E4D`。卡片和道具共用该选择器。

选择器通过合法、非法和边缘滚屏光标反馈目标状态；左键确认、无效点击和
右键取消分别播放对应音效。右键取消受 mask 的 `0x08` 标志控制。
选择器不绘制额外的地图或路线操作提示横幅，callback 内没有
`0x44FABC` 或 `0x440CAC` 文字提示调用。

对象类别、mask、输入和光标资源见
[原版目标选择器](../../../rich4/docs/target_selection.md)。
