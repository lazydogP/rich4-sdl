# V3.11 macOS 音乐导入依据

2026-11-05 使用 IDA Pro MCP 复核仓库本地 V3.11 `Rich4.exe.i64`。原始反编译输出保存于 `macos-music-ida.json`。这是平台导入映射，游戏逻辑和存档格式不变。

- `0x454D91`：非零参数选下标 `n-1`，零参数推进 `(index+1)&7`。`byte_47E770 == 0` 时打开 `off_47E773` 指向的 MIDI；CD 分支播放 `index+2`。
- `0x454BCC`：MIDI 恢复分支仍引用 `off_47E773`，并恢复之前记录的播放位置。
- `0x4549CF`：固定曲目先清除 `0x8000` 标志，再查 `off_47E793`，仅走 MIDI 分支。
- `0x4545BA` 的 `0x454643: cmp eax, 9` 和 `0x454646: jnz 0x454767`：CD 音轨数恰为 9 时才在 `0x45464C` 将 `byte_47E770` 置 1。
- IDA 读取 `0x47E773..0x47E7D6` 的 25 个指针与 `0x4662D0..0x4663E6` 字符串：8 首 RICH 顺序为 `RICH08, RICH16..RICH22`；固定表为 `MIDI01..MIDI13, MIDI14-1, MIDI14-2, MIDI15, MIDI16`。
- `0x415872` 在 `0x415888` 打开 JUMP.MKF，载入条目 45、46 与角色条目；AVI 失败后 `0x41596F` 进入该资源回退序列。

Apple 渲染自动验证：25 首合计约 1986.16 秒，PCM 音频约 350.36 MB，每曲有实际非零音频，WAV 帧数与 MusicSequence 曲尾秒数舍入到帧一致。人工试听、桌面和正式发布验收尚未完成。8 首 RICH 与 MultiverseJourney 的音乐身份仍需人试听确认，不能由时长相近代替。
