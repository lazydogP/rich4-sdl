# `0x450CED` / `0x45144F` Autodesk Animator FLC

- 地址与目标模块：`0x450CED` 初始化、`0x45144F` 逐帧播放；`resource/flc_animation.c`。
- IDA 结论：2026-07-11 已复核两函数。`0x450CED` 大小 `0x217`，确认 `+4 == 0xAF12`、宽高/帧数/header delay 字段和 128 字节 header；`0x45144F` 确认初始化后按 `timeGetTime` 逐帧播放并轮询消息。flags、override、逐帧等待与声音顺序于 2026-10-16 通过 IDA 再次确认。
- 本地证据：[`../../rich4/asm/rich4.asm`](../../../rich4/asm/rich4.asm) 第 70180 行开始在 `+4` 校验 FLC 文件魔数 `0xAF12`，读取 `+6/+8/+0xA` 和 `+0x10` 字段，并将数据指针推进 128 字节；第 70867 行开始的播放器调用初始化、使用 `timeGetTime` 推进并轮询消息。多个独立 asm 模块调用 `0x45144F`，例如 [`../../rich4/asm/rich4_card_chaichuka.asm`](../../../rich4/asm/rich4_card_chaichuka.asm) 第 266 行。
- 置信度：`confirmed`（当前 decoder/player 边界及 V3.11 实际 opcode 集）。
- 测试链接：[`tests/resource/test_flc_animation.c`](../../tests/resource/test_flc_animation.c)、[`tests/resource/test_flc_player.c`](../../tests/resource/test_flc_player.c) 和 [`r2-flc-real-resource-scan.md`](r2-flc-real-resource-scan.md)。实现位于 `resource/flc_animation.c` 与 `resource/flc_player.c`。
- 缺口/冲突：V3.11 未观察到的未知画面 opcode 仍明确报 unsupported；opcode 18 仅作为边界已验证的附属预览 chunk 跳过。`0xAF12` 只记录为 FLC 文件魔数，不作为格式名。


## 逐帧计时和声音顺序（2026-10-16 IDA 复核）

`0x45144F` 在每轮循环开始调用 `timeGetTime`，再调用 `0x450F04`
解码、合成并提交一帧；仅等待本轮剩余的帧间隔。最后一帧也完成本轮等待后
才返回。慢帧消耗自己的间隔，下一轮重新取时间，不按整段播放起点计算目标帧，
也不补播累计欠下的历史间隔。

`0x450CED` 从 FLC header `+0x10` 读取间隔；调用 flags 的 `0xF0` 位非零时，
覆盖为 `10 * ((flags >> 4) & 15)` ms。flags 的高字节用于按解码帧数触发声音，
`BYTE2(flags)` 用于指定重绘时机，二者不属于帧间隔。`0x450F04` 持续推进
`0x476378`，保留差分与调色板状态，只有循环边界才回到首帧数据。

普通带音效的 FLC：`0x45144F` 先调用 `0x454304` 准备音效。它通过
`0x454395` 停止并释放上一份共享效果缓冲 `0x47E754`，装载新的 Effect 资源。
第一次 `0x450F04` 返回后，`0x45434F` 才开始播放。语音缓冲独立为
`0x47E750`，不会让动画按语音的已播放时长跳帧。

新闻 `0x44B6DF`、命运 `0x44DB81` 先加载所选事件图与 Panel[66]，然后在
构造页面文字时进入 `0x44FABC`。文字开头的 `#dddd` 标记调用 `0x45441A`
装载并立即播放语音；整页随后提交到前台。`0x4544F6` 等待语音结束，并补足
新闻 2400 ms／命运 1600 ms 的最短页面等待；用户释放按键或鼠标可结束这段等待。

开局 `0x415872` 预先加载 Jump[45]、Jump[46] 及所选角色两组动画，整段结束后
释放。flags `0x14000003` 的声音钩子在一基第 20 帧触发；骰子 `0x419572`
传入 `0x1E000000`，钩子在一基第 30 帧触发。对应零基帧索引分别为 19、29。
开局 flags 的 bit1 允许中断；新闻后续动画、拘禁和出国调用的该位为零。

原始反编译输出：`build/miyoo/original-flc-playback-audio-ida.json`、
`build/miyoo/original-flc-voice-waits-ida.json`。前者包括播放、逐帧解码、
初始化、声音准备、页面构造、跳伞／骰子和五个新闻动画调用点；后者记录语音与等待。
