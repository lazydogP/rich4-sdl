# 主菜单设置、路面宝箱与售出头像

核验来源：IDA Pro MCP，`assets/original/Rich4.exe.i64`；资源尺寸由
`assets/original/V3.11/{Data,Map,Panel}.mkf` 实际解包读取。

## 主菜单设置

2026-10-17 经 IDA Pro MCP 实时核对 `0x411B53` 与
`0x411DB1..0x411DE9` 的尺寸取半指令，见
[反编译及指令记录](2026-10-17-ui-turn-order-ida.json)。

- `0x411B53` 从句柄 `0x48A0E4`（Data.mkf）加载资源 3。
- `rich4/asm/rich4_ui_options.asm` 的同一入口在加载后读取 chunk 0
  宽高，以 `(320 - width/2, 240 - height/2)` 确定设置窗口矩形；
  `sar` 对宽高分别取半，矩形同时用于窗口绘制和输入坐标。
- `0x4103A3` 主菜单分支直接调用 `0x474D68` 中的三个回调：
  `0x4119E3` 日期、`0x411A86` 热键、`0x411A96` 游戏说明。
  游戏中同位置的按钮走另一条确认流程。
- 日期：`0x410AC3` / `0x40FF4B`，Data[3] chunk 2（199×220），
  左上角 `(320-width/2, 240-height/2)`；月份循环，年份下限 1998，
  使用原版 `year%4` 闰年规则。重置取系统日期，确认独立提交日期，
  之后取消外层设置不撤销日期。切月不擅自截断原日号。
- 热键：`0x411122` / `0x410158`，Data[3] chunk 1（328×336）。
  28 项，前 8 项只读；接受键表 `0x47EDFA`，默认值 `0x47EDC2`，
  支持 CTRL 组合，拒绝重复，编辑中右键先恢复原值。
  确认复制 56 字节至 `0x497168` 并调用 `0x411F80` 保存配置。
- 原始 Big5 文本表：`0x474ABC`（热键名称）、`0x474B2C`（按钮）、
  `0x474C98`（月份）、`0x474CC8`（日期按钮）；保存于
  `src/platform/sdl1/render/options_original_text.h`。
- 游戏说明：`0x411A96 -> 0x44EB39(-1,-1)`，复用已有 Help.mkf 查看器。

本次热键工作覆盖设置编辑、配置保存及接受键映射；未扩展已有游戏流程尚未
接入的其他快捷键命令。不能将设置面板完成解释为全部游戏快捷键均已实现。

## 路面可拾取宝箱

用户明确指定路面可拾取宝箱，不是固定的抽卡宝箱格。

`0x41B42D` 的动态物体 type 14 分支（`0x41BB29` 起）：

1. 普通玩家最后一步停在宝箱上才触发，经过不拾取。
2. 播放 `0x482382` 指向的 Effect.mkf[36]。
3. 移除动态槽 14，刷新地图。`0x40E14D` 保留固定 type 14；
   宝箱不会立即重新生成，月初流程 `0x41CF67` 负责重建。
4. `0x440CAC` 显示「得到５００點券！」，等待 1500ms。
   内部 `0x4528B9` 可被 WM_KEYUP / WM_LBUTTONUP / WM_RBUTTONUP 提前结束。
5. 等待结束后给玩家 `+48` 的 uint16 点券字段加 500。
6. 调用 `0x44EF41`，使用角色 27 项台词表 `0x48084A` 的第 0 项，
   沿用现有角色语音/台词持续时间流程，之后继续回合。

SDL 实现复用 special_reward 的 action 14，等待期间不播放抽卡 FLC。
按下事件被提示框消费，释放事件只结束提示，避免穿透触发工具栏。

## 路面礼品（动态 type 13）

`0x41B42D:0x41B8F9..0x41B98B`，以本次 IDA Pro MCP 反编译及
`rich4/asm/rich4.asm` 的对应块为依据：

1. 普通玩家最后一步停留才拾取，经过不拾取。
2. `0x445ADA` 按公共库存数量加权抽取前八种道具，并调用 `0x445A4D`
   尝试入库。公共库存为空则不移除礼品、不播放拾取音效、不显示提示。
   已持有九个的道具仍参与抽取；抽中时不增加持有量、不扣公共库存，
   但外层仍移除礼品并展示“得到”提示，保留原版这一行为。
3. 播放描述符 `0x48237A` 的 `Effect.MKF[35]`，移除动态槽 13，刷新地图。
   地面外观使用 `Data.MKF[408]`，消失后不立即重新生成。
4. `0x440CAC` 以 Big5 格式串 `0x463AA8`（“得到%s！”）显示道具名称
   1500 ms。背景为 `Data.MKF[517]` chunk 5，无开箱 FLC、无道具大图。
   `0x4528B9` 接受键盘、鼠标左键、鼠标右键释放以提前结束等待。
5. `0x44F230` 按道具价格选角色反应：1..50 用第 2 项，51..100 从第
   0/1 项随机，超过 100 用第 0 项。`0x44EF41` 使用 `Data[517]`
   chunk 6、`Map[27+character]` chunk 1 和台词 `#dddd` 对应的
   `Speaking[dddd]`；复用角色语音结束/最少 1000 ms/释放跳过逻辑。

SDL 由 `rich4_road_gift_begin` 接入自然停步路径，复用 special_reward 的
展示标签 15（不是地图 action 15），其既有 card 字段保存零基道具 ID，
因此不改变存档布局。提示期间先消费按下事件，释放仅结束提示，不穿透工具栏。
`test-road-gift` 覆盖停留/经过、提示到角色反应的时序、提前跳过、空库存及
持有量九个的原版边界，同时回归路面宝箱和音频事件队列。

## 售出面板头像

- `0x4284BE` 对人类玩家（玩家 `+21 == 1`）进入面板；从句柄
  `0x48A05C`（Panel.mkf）加载 73、74。
- `0x407AD2` 在 `0x407AE5` 打开 Map.mkf，`0x407FC7` 加载
  `Map.mkf[27 + character]`。头像为 chunk 0。
- `0x428817` 遍历所有参与玩家，不按有无商品、AI 或存活状态过滤。
  头像锚点为面板内 `(44,84+72*player)`；面板位于 `(22,66)`，
  因而屏幕锚点是 `(66,150+72*player)`。使用原图尺寸及原图热点，不缩放。
- `0x407FD6`：`play_state==0 && engineering_saved_traffic_method==0` 时
  灰度处理；`0x455480` 对非零 RGB555 像素使用
  `(R5+G5+B5+16)>>2` 作为三个通道，透明零不变。
- 开局未落地玩家同样显示彩色头像：绘制循环不检查地图坐标或落地标志。
  `0x406DE7` 的 `0x4072F9` 将玩家原始 `+100` 字段暂存为 1/2（人类/AI）；
  因此未落地时 `+21` 即使为 0，也不会满足加载头像的灰度条件。
  `+100` 后续还被工程车复用，不能把该字节非零只解释为工程车状态。
- `0x42704E` 商品详情显示名称和物品图标，没有额外的人物头像。

## 游戏内三个设置按钮复核与修复

- 三个按钮均由 `0x410831` 按鼠标按下时保存的按钮号在释放时派发，
  不再命中测试释放位置；随后 `0x453A32(320,200)` 显示 Data.mkf[440]。
  `0x45367E` 将指针置于确认框左上角加 `(22,22)`，右键释放取消；
  键盘匹配配置的 Yes/No（热键 8/9，默认 Y/N），不依赖当前悬停半区。
- **重新游戏**：`0x411AA3` 读取当前系统日期、写 `0x497160`，设
  `0x46CAF8=1`；WinMain `0x401DE8` 返回外层主菜单。
  SDL 保留返回主菜单行为，补上日期重置，不提交外层未确认的设置草稿。
- **结束游戏**：`0x411B46` 调用 `0x411F80` 保存已提交配置，然后设置
  `0x46CAF9=1`；WinMain `0x401E0A` 清理并销毁窗口。
  修正原先误回主菜单的实现，改为停止场景循环、执行正常退出清理。
- **认输投降**：`0x411AE0` 先调用 `0x40CD87` 完成退场、动画、拍卖和台词。
  初始人类玩家数 `0x499104 > 1`，且 `0x40DFDA` 检出仍有人类玩家时，
  再调用 `0x4339D9`；候选为除认输者以外的全部存活玩家（含 AI），
  至少两名才打开死神复仇选择。
- 复仇 UI `0x433088`：使用 Panel.mkf[18] 背景和 chunk 8 文字框，
  Data.mkf[2] 的 72×72 角色图，两个候选 x 为 238/330，三个为
  211/284/357，y 为 348；坐标表 `0x4757D8`。
  Speaking[42]（询问召唤死神）→ Speaking[43]（选择目标）→ 选择，
  每句沿用 `0x44EE18` 的至少 2000ms 且等待语音结束规则。
  左键按下选择后 Speaking[41] → Panel.mkf[20] 动画 → 返回目标；
  右键释放可以取消，键盘不选择目标，最终 FLC 不可用右键中止。
- `0x411B35 -> 0x40E033(15,0,7,target+1)` 分配首个空闲死神槽
  （零基 14/15）并走 `0x40EAD7` 的替换附身流程。SDL 复用神明效果与
  脱离/附身展示，期间视口对准目标，完成后恢复原回合。
- 复仇流程复用 magic_house 展示状态，condition 12 明确区分原版第二个
  回调；认输等待标志属于禁止玩家手动存档期间的临时延续状态，未改存档版本。
