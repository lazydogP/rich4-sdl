# 原版文字渲染参数

本文记录《大富翁 4》原版 `0x44F9D8` 与 `0x44FABC` 的参数语义。
依据为 IDA Pro 中的原版 `Rich4.exe` 与
`rich4/asm/rich4_text_drawing.asm`。

## 原版入口

```c
/* 0x44F9D8 */
create_font(height, main_rgb, effect_rgb, style, spacing);

/* 0x44FABC */
draw_text(destination, text, x, y, mode);
```

`0x44F9D8` 固定请求 Big5「細明體」、charset `0x88`，字体高度为
`-height`。两个颜色参数使用 `0xRRGGBB`，原版在交给 GDI 前交换红蓝
通道，以适配 `COLORREF` 的 `0x00BBGGRR`。

## 字体样式参数

`style` 是位标志，不是互斥枚举。

| 位 | 值 | 原版行为 |
|---|---:|---|
| 0 | `0x01` | 用效果色在 `(1,1)` 先画一次，形成右下阴影 |
| 1 | `0x02` | 字重使用 700；未设置时使用 400 |
| 2 | `0x04` | 用效果色在 `(1,0)`、`(1,2)`、`(0,1)`、`(2,1)` 画四向描边 |
| 3 | `0x08` | 最终复制文字像素时使用全局 `draw_rect` 裁剪 |

阴影和描边的选择顺序为：

```c
if (style & 1)
    draw_shadow();
else if (style & 4)
    draw_outline();
```

所以 bit 0 和 bit 2 同时出现时，效果分支选择阴影。但正文字形是否偏移
到 `(1,1)` 仍直接检查 bit 2。

原版调用点中可见的固定组合包括：

| `style` | 组合 |
|---:|---|
| `0` | 常规 |
| `1` | 常规 + 阴影 |
| `2` | 粗体 |
| `3` | 粗体 + 阴影 |
| `4` | 常规 + 描边 |
| `6` | 粗体 + 描边 |
| `0x0B` | 粗体 + 阴影 + `draw_rect` 裁剪 |

`0x44FA3F` 执行 `test ..., 2`，字重由 style bit 1 决定：

```c
weight = (style & 2) ? 700 : 400;
```

## 字距参数

横排使用：

```c
SetTextCharacterExtra(hdc, spacing - 1);
```

因此 `spacing=0/1/4` 分别对应 `-1/0/+3` 像素附加字距。

模式 3 的逐字竖排步长为：

```c
advance = height + spacing + ((style & 6) ? 1 : 0);
```

## 游戏主界面右侧竖排标签

IDA 在 `0x415F69` 中确认四个右侧标签的调用为：

```c
/* 0x4161B3 */
create_font(18, active ? 0x101010 : 0x404040, 0, 2, 0);

/* 0x4161D7 */
draw_text(NULL, tab_text[index], 627, tab_y[index] + 20, 3);
```

`0x415F73–0x415F82` 从 `0x415D0D` 连续复制四个未对齐的 DWORD，解码为
`15, 88, 158, 230`。加上调用点的 `20` 后，四个中心坐标是：

```text
35, 108, 178, 250
```

因此这组文字是 **18 像素粗体、无阴影、无描边、spacing=0、模式 3
逐字竖排**。`0x44F7C7` 计算出的逐字步长为：

```c
18 + 0 + 1 == 19
```

其中最后的 `+1` 来自 `style & 6`。效果色虽然传入 `0`，但 `style=2`
不会进入阴影或描边分支，所以不参与绘制。

原版 `0x44F9D8` 给 `CreateFontA` 的 quality 参数是 `0`
（`DEFAULT_QUALITY`），遵循操作系统的字体平滑设置。

## 原版临时文字表面与透明复制

原版临时文字表面的调用顺序为：

1. `0x44F935` 创建一个 `512×200` 的 16 位 DirectDraw 表面，并把
   `0x32000` 字节全部清零。
2. `0x44FABC` 通过该表面的 HDC 绘制文字，背景模式为
   `TRANSPARENT`。
3. `0x44F70C` 逐个读取 16 位像素，只有像素值非零才计入实际文字边界。
4. `0x455FD9` 系列复制函数也只复制非零像素。
5. `0x450042` 在复制后把使用过的矩形重新填零。

零像素既是临时背景，也是透明复制标记；非零像素参与边界扫描和复制。

## 绘制目标与文字参数

- `destination == NULL`：复制到当前 640×480 主画面。
- `destination != NULL`：复制到调用方提供的 `graph_st`。
- `text == NULL` 或空字符串：不绘制。
- `text` 以 `#dddd` 开头时，原版先把四位十进制编号交给
  `0x45441A` 播放语音，再跳过五字节前缀绘制正文。
- Big5 高位字符每次消费两个字节；ASCII 每次消费一个字节。

## `mode` 排版与锚点

原版先在临时表面绘制，扫描实际非背景像素得到 `width/height`，最后按
下表修正目标坐标。

| `mode` | 坐标修正 | 排版 |
|---:|---|---|
| `0` | 无 | 左上锚点 |
| `1` | `x -= width` | 右上锚点 |
| `2` | `x -= width/2; y -= height/2` | 中心锚点，行内普通左对齐 |
| `3` | 同模式 2 | 逐 Big5/ASCII 字符向下竖排 |
| `4` | 同模式 2 | 中心锚点，各行使用 `DT_CENTER` |
| `5` | `y -= height/2` | 左中锚点 |
| `6` | `x -= width; y -= height/2` | 右中锚点 |
| `7` | `x -= width/2; y -= height` | 中下锚点，各行使用 `DT_CENTER` |

模式 2 与模式 4 对单行通常相近；多行时模式 2 保持各行左对齐，模式 4
将每一行相对最长行居中。

## AI 托管面板文字

AI 托管面板的静态文字由 `0x41E345` 先画进 `Panel.MKF[77]` 的图块，
`0x41DB91` 再把图块放到屏幕 `(102,62)`。IDA 中的原版参数为：

| 调用范围 | 高度 | 主色 | 效果色 | style | spacing |
|---|---:|---:|---:|---:|---:|
| `0x41E375–0x41E3D5` 三个标题 | 20 | `0xF0F0F0` | `0x101010` | 3 | 1 |
| `0x41E3ED–0x41E519` 九组标签 | 16 | `0xF0F0F0` | `0x101010` | 3 | 1 |
| `0x41E52E–0x41E56F` 确定/取消 | 20 | `0x101010` | `0` | 2 | 1 |

`style=3` 是粗体加 `(1,1)` 右下阴影。标题和标签使用浅色正文、
深色阴影。对应 RGB565 值是：

```text
0xF0F0F0 -> 0xF79E
0x101010 -> 0x1082
```

“确定/取消”的原始字符串字节也必须原样保留：

```text
lpchText__89 @ 0x463D2E: BD 54 A9 77 00
lpchText__90 @ 0x463D33: A8 FA AE F8 00
```

两组汉字之间都没有 `0x20` 空格。`mode=3` 会进入 `sub_44F7C7`，逐个
SBCS/DBCS 字符调用 `TextOutA`，纵向步进为
`font_height + spacing + ((style & 6) != 0)`；本调用即 `20+1+1=22`
像素。

### 托管“使用卡片”字符串

`0x41E40C` 使用 `lpchText__80 @ 0x463CF3`。原始字节为
`A8 CF A5 CE A5 64 A4 F9 00`，正文为“使用卡片”。
托管面板的 14 个静态字符串位于 `0x463CD8..0x463D37`。
