# 加油站与旅馆：收费、入住和退房

## 地址与目标模块

- `0x41A421..0x41A480`：旅馆逐等级房价、转盘及原始费用提示。
- `0x41A4DB..0x41A529`：加油站交通倍率和骰子总点数计费。
- `0x41D559 / 0x41D709 / 0x40FBB8`：免营业、神明费用调整及代付。
- `0x41A761..0x41A85E / 0x40D761 / 0x44BA63`：入住者、旧离场状态及保险理赔。
- `0x40D5A5 / 0x40DD1F / 0x40D7C4 / 0x40C05C / 0x40829D`：迁入、移动、半程隐藏及绘制条件。
- `0x41C84F / 0x40D6BE / 0x418EBD / 0x40C912`：住宿递减、退房、恢复朝向及回合提示。
- 模块：`core/facility.c`、路线执行器 continuation、`app/hotel_flow.c`、
  `app/turn_rotation_flow.c`、`app/insurance_flow.c`、ViewModel 和 SDL 提示渲染。

## 本地证据与行为

详尽原版分支记录见 `../rich4/docs/facility_company.md` 第 2.3.1、5.7 节。

- 无主先购买，自有先建造/升级，他人已建成设施才收费。旅馆上限 5 级，加油站上限 1 级。
  梦游阻止购建。查封、同盟、主人死神附身或主人处于离场/冬眠/梦游状态会免营业。
- 加油原始费用为 `500*物价指数*骰子总点数*(1<<(交通低两位-1))`。
  步行不收费，交通值 1/2/3 分别对应机车/汽车/工程车；涨价不使加油费翻倍。
- 旅馆房价读取设施 `+0x24+2*level`，先乘物价，涨价时翻倍，再乘转盘住宿天数。
  `0x475D18` 的 12 字节为 `FF FF 01 FF FF 04 FF 03 FF FF 02 FF`。
  房费提示原文 `0x4639FF` 为“休息%d天／费用%d元！”，展示 1500 ms 后付款。
- 小财神减半、大财神归零、小穷神加 50%、大穷神翻倍。大财神归零时整个入住分支结束。
  旅馆不尝试免费卡；嫁祸/神明代付后的最终付款人承受入住。
- `0x40D761` 清旅馆、出国、监狱、医院状态；不清车辆或骰子数。
  住宿写 `天数-1`，1 天写 `0x80`。有保险时先展示 2000 ms 理赔提示，
  再将 `2000*物价指数*天数` 加入入住者现金，随后累计离场天数并迁入。
- 本人入住保留道路节点，移除道路 occupancy，设置 `play_state|0x20`，
  朝建筑记录坐标启动一个移动段。代付者直接迁入，并复制踩地者道路记录。
- 固定移动时长局部值为 `float(sqrt(dx²+dy²)*0.125)`，每 tick 用 float 累加坐标；
  剩余 tick 小于初始整数 tick 的一半时清 `0x20`。住宿仍非零，`0x40829D` 从绘制队列
  排除人物；位置继续推进到建筑。到达后下一 pulse 停移动音，再经过 5+3 个等待 tick。
- 退房仍保留 `0x80` 住宿标记，设置 `0x10`，由建筑移回道路；半程后清离场四字节，
  人物重新出现。到达后的等待结束，`0x418EBD` 恢复原朝向、清 `0x30`，保留同一玩家，
  不额外推进日期或扣住宿天数。
- 住宿期间 `0x4631E0` 提示“%s住宿中／还剩%d天！”，按 `(计数&0x7F)+1`
  展示 1500 ms，无医院/监狱的随机反应语音。
- 人物移动归档为 `0x48A0E4 = Data.MKF`。普通陆地移动资源为
  `128+21*角色+3*交通低两位+1`，含 8 方向；已有水路/梦游状态采用对应人物资源。
  入住链未调用独立 FLC 特效入口 `0x45144F`。
- 复用移动循环 sound ID 44/45/46/53（水路 47），有附着炸弹时另播 32。
  20 ms timer 经 `{6,4,2}` 节流，三档名义移动 tick 为 120/80/40 ms。
