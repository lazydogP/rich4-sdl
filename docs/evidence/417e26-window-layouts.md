## 坐标与资源

坐标为 640×480 原版画面的绝对像素。图块实际左上角为调用锚点减去
SPR/SMP 描述符的 `x/y`；不按矩形中心重新定位或缩放。文字先测量、裁边，
再按原版对齐模式定位，字号不是整段文字的固定矩形宽高。

| `RICH4.CFG +5` | 上部玩家栏 | 小地图 | 日月历 |
|---|---|---|---|
| 0 日月历 | `(440,0) 200×280` | 隐藏 | `(440,280) 200×200` |
| 1 小地图 | `(440,0) 200×280` | `(440,280) 200×200` | 隐藏 |
| 2 组合画面 | `(440,0) 200×80` | `(440,80) 200×200` | `(440,280) 200×200` |

主地图三种模式均为 `(0,40) 440×440`。工具栏的逻辑区域为 `(0,0) 440×40`，
背景 `Panel.mkf[1]/chunk 0` 本身为 439×40；11 个按钮的锚点为 `(20+40*i,20)`，
普通/悬停图块分别为 `i+1` 和 `i+12`。不额外绘制主地图和侧栏边框。

### 玩家栏

`Panel.mkf` 的句柄为 `0x48A05C`，`Data.mkf` 为 `0x48A0E4`。
完整栏使用 `Panel[0]/chunk 0..3`；简化栏使用 chunk 4；特殊 Actor 栏使用 chunk 5。

| 元素 | 完整栏 | 简化栏 |
|---|---|---|
| 主头像 | 锚点 `(482,40)`，`Map[27+character]/chunk 0` | 同左 |
| 盟友头像 | 锚点 `(524,64)`，盟友角色 chunk 1 | 同左 |
| 角色颜色条 | `(522,56) 86×12`，阴影 `(523,57)` | `(528,32) 106×4`，阴影 `(529,33)` |
| 姓名 | `(564,40)`，22px，中心，spacing 0 | `(582,16)`，20px，中心，spacing 0 |
| 现金标签/数值 | `(450,80)` / `(600,102)` | `(530,40)` / `(634,41)` |
| 存款标签/数值 | `(450,145)` / `(600,166)` | `(530,62)` / `(634,63)` |

完整栏三行标签为 12px、左上对齐、spacing 1；数值为 22px、右上对齐、spacing 0，
第三行标签/数值为 `(450,208)` / `(600,230)`。简化栏标签和数值均 12px、spacing 1，
数值右上对齐。标签按 `0x41805D/0x41808A` 先写入背景，再叠加头像。

完整栏四页为资金（现金/存款/总资产）、地产（土地/连锁店/设施）、
股票（总市值/成本/经营权）、其他（点券/贷款/保险期）。页签竖排中心点
`(627,35/108/178/250)`，字号 18px、spacing 0；点击区域为 `x∈[616,640), y∈[0,280)`，
按 `y/70` 选页。组合模式不响应这些区域及信息换页快捷键。
`0x48BE24` 为每个玩家分别保留当前页；点击已选页不重复播放选择音效。
物价指数在 `(450,260)`，12px、左上对齐。有贷款且期限非零时，在 `(500,146)`
绘制剩余天数，12px、左上对齐。

小头像的状态字段是玩家记录 `+65` / `0x496BA9`（盟友编号+1），
由同盟卡 `0x445710` 写入；不是 `+63` 的神明附身字段。
角色资源保留原尺寸及锚点。特殊 Actor 4..7 的姓名为小偷、强盗、流氓、间谍；
完整/简化姓名中心为 `(582,40)` / `(582,20)`，字号为 22/20px，
其角色小头像锚点 `(524,64)`。

### 日历/月历

`RICH4.CFG +12` / `0x497164`：0 日历，非零月历。SDL 以 `calendar_view`
命名此字节，保持 72 字节配置格式和 `+16` 快捷键偏移。
月份背景映射为 `[3,0,0,0,1,1,1,2,2,2,3,3]`。

| 元素 | 原版定位 |
|---|---|
| 日历背景 | `Panel[2]/chunk season`，`(440,280) 200×200` |
| 特殊日期背景 | `Data[base[map]+event]` 原始 200×200 像素，base=`[4,28,47,67,87,108,95,118]` |
| 月历背景 | `Panel[2]/chunk season+4`，`(440,280) 200×200`，按钮/星期表头已包含在背景中 |
| 日历太阳/月亮 | chunk 8/11，锚点 `(462,300)` / `(492,301)`；实际 `(450,289) 24×23` / `(482,291) 20×20` |
| 年份 | `(580,288)`，24px、左上对齐 |
| 月份 | `(500,328)`，28px、中心 |
| 日历星期 | `(454,352)`，16px、竖排中心 |
| 日历大号日期 | `(500,376)`，60px、中心 |

年份/月/星期/大号日期的 spacing 为 1，描边 style 6。普通日期深色字、白色描边，
星期日及特殊背景日期红色字、深色描边。
按钮点击区域为太阳 `x=448..474`、月亮 `x=478..504`，`y=288..314`，端点均包含。
仅在日月历/组合模式响应；切到同一页不重复播放选择音效。

月历设当月1日星期为 w（星期日=0），日期为 d，q=w+d-1。
日期中心为 `x=470+23*(q%7), y=378+14*(q/7)`，12px、中心、spacing 1、style 2。
当天红色空心框位于 `(x-10,y-6) 20×14`；星期日及地图节假日按 `0x4523D5` 标红。

### 小地图

底图 `Map[16+stage*4+map]/chunk 0`，200×200。原版地形已有道路，不另加道路节点点阵。
土地标记用 `Data[517]/chunk 22+(variant&1)`，设施/公司用 `24+(variant&1)`，
保留 3/5/7/11 像素图块轮廓，所有非零像素染成业主角色颜色。

地图点锚点为 `x=440+((5696*world_x)>>16), y=T+((5696*world_y)>>16)`，T=280/80。
玩家图标为角色 chunk 6；当前 Actor 白框 30×30，固定观察位置红框 30×30，均偏移 -15。
初次落地前没有玩家小图标或白框。

旋转按钮锚点为 `(443,T+3)` / `(468,T+3)`，25×26；普通图块 20/21，按下图块 18/19。
鼠标按下记忆按钮并显示按下图块，松开后才按 `(direction±1)&7` 旋转。
观察位置使用 `((761856*local)>>16)` 反投影，钳制到 220..2084。
主界面输入有效时，在显示的小地图内部释放右键清除观察位置并恢复跟随；模态窗口保留其输入所有权。
视窗组快捷键按 0→1→2→0 循环，信息页向上/下按四页循环。
