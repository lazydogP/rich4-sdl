# 顶部“帮助”按钮：原版行为与资源

本文记录游戏顶部工具栏第一个按钮的完整还原依据。实现入口位于
`src/platform/sdl1/runtime_main.c`，原版权威入口为：

- `0x417E26`：顶部工具栏鼠标/绘制回调。
- `0x417D65`：顶部工具栏 11 项分派；索引 `0` 调用
  `sub_44EB39(20, 60)`。
- `0x44EB39`：加载 `Help.mkf`、初始化帮助状态并进入模态消息循环。
- `0x44E40B`：帮助面板输入回调。
- `0x44DFB4`：按分类、条目和滚动状态重绘完整面板。
- `0x44DD9F`：正文上一页/下一页。
- 对照反编译源码：
  `rich4/asm/rich4_ui_clicking_top_panel.asm`、
  `rich4/asm/rich4_ui_help.asm` 和
  `rich4/csrc/fcn_417d65.c`。

## 动画与语音资源

- 动画资源：无。帮助面板没有 FLC、逐帧图或计时动画。
- 语音资源：无。帮助面板不访问 `Speaking.mkf`，没有角色语音。
- UI 的“普通/选中/按下”变化全部是静态 SMP 子图切换，不应归类为
  动画。

## 音效资源

| 资源 | 触发 |
| --- | --- |
| `Effect.mkf[0]` | 鼠标从工具栏其他区域进入顶部“帮助”按钮槽；同槽内移动不重播 |
| `Effect.mkf[1]` | 按下顶部“帮助”；帮助窗内按下六类有效控制区中的任意一个；正文多页时按配置的上一页/下一页热键 |
| `Effect.mkf[4]` | 帮助窗内任意位置右键释放并关闭 |

帮助窗内部没有悬停音效。分类/条目/箭头区域以外的左键不播放音效。
在滚动或翻页边界上，只要按下点仍落在对应有效控制框中，
`Effect.mkf[1]` 仍会播放，即使释放后状态不再变化。

## 可交互 UI 行为

下表坐标均相对帮助面板左上角 `(20,60)`。

| 控件 | 命中框 | 事件 | UI/状态变化 |
| --- | --- | --- | --- |
| 8 个分类 | 分类总框 `(22,38)-(91,361)`；各项 `(26,58+36n)-(92,91+36n)` | 左键按下 | 当前分类切换；条目重置为 0；正文重置到第一页；绘制子图 1 |
| 最多 8 个可见条目 | 总框 `(104,78)-(196,361)`；各项 `(108,78+34n)-(193,111+34n)` | 左键按下 | 当前条目切换；正文重置到第一页；旧项用子图 2，新项用子图 3 |
| 列表向上 | `(170,43)-(192,58)` | 按下/释放 | 按下时子图 4→6；释放时最多向上 8 项，选择项同步移动；顶部释放不改变状态 |
| 列表向下 | `(170,59)-(192,74)` | 按下/释放 | 按下时子图 5→7；释放时最多向下 8 项，选择项同步移动；底部释放不改变状态 |
| 正文上一页 | `(322,48)-(345,80)` | 按下/释放 | 仅多页正文显示；按下时子图 8→10，释放回到上一页；第一页释放不改变页码 |
| 正文下一页 | `(343,48)-(366,80)` | 按下/释放 | 仅多页正文显示；按下时子图 9→11，释放进入下一页；末页释放不改变页码 |
| 正文热键 | `RICH4.CFG` 偏移 66/68，即 `hotkeys[25]/[26]` | 键盘按下 | 多页正文上一页/下一页；默认分别为 Page Up/Page Down |
| 关闭 | 面板内外均可 | 右键释放 | 播放取消音效、恢复打开前画面、退出模态帮助 |

其他状态规则：

- 帮助打开期间原游戏消息处理和游戏更新暂停。
- 帮助背景取自软件鼠标合成前的完整游戏帧；当前鼠标在面板之上单独绘制，
  不会把点击“帮助”时的指针烘进背景。
- `0x4018E7` 暂停的是外层游戏流程，不会停止窗口消息分派；SDL 在帮助
  打开期间继续处理主地图播放列表的曲目结束并接续下一首 BGM。
- 每次打开都回到分类 0、条目 0、正文第一页。
- 八个分类各自的条目列表滚动位置在同一进程的多次打开之间保留；
  这是原版静态滚动字段未在 `0x44EB39` 重置的结果。
- 左键按下决定分类/条目；滚动与正文翻页在左键释放位置决定动作，
  与原版 `WM_LBUTTONDOWN`/`WM_LBUTTONUP` 分工一致。
- 帮助内部没有 hover 高亮；只有当前分类、当前条目和按住箭头时的
  子图变化。
