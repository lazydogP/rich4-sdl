# 顶部“地图”按钮：全地图模态 UI、资源与交互

本文记录游戏顶部工具栏第 6 个按钮（索引 `5`）的完整还原依据。
实现入口位于 `src/platform/sdl1/runtime_main.c`，所有原版行为均以
Rich4.exe V3.11 固定 IDB 和 `../rich4` 反编译源码交叉确认。

## 地址与控制流

| 地址 | 职责 |
| --- | --- |
| `0x417E26` | 顶部工具栏回调：hover、左键按下记忆命令、左键释放分派 |
| `0x417D65` | 11 个顶部按钮的分派；case `5` 调用 `sub_40A9BD` |
| `0x40A9BD` | 以 `sub_40A801` 进入嵌套模态循环；退出后调用 `sub_415E70(1)` 重绘主地图 |
| `0x40A801` | 全地图初始化、绘制和右键释放关闭 |
| `0x40A4E1` | 合成全地图/侧栏小地图底图和地产归属标记 |
| `0x456384` | 将归属标记的所有非零像素染成业主角色代表色 |
| `0x407AD2` | 加载地图概览、归属标记和角色地图图形资源 |

IDA Pro MCP 于 2026-07-29 重新确认：

- `0x417E26` 在顶部 `x < 440, y < 40` 时按 `x / 40` 计算按钮。进入
  新槽播放 `ref_48231A`；左键按下播放 `ref_482322` 并保存
  `x / 40 + 100`；左键释放才调用 `sub_417D65(saved - 100)`。
- `0x40A9BD` 只调用 `sub_4018E7(sub_40A801, 0)` 和
  `sub_415E70(1)`。
- `0x40A801` 只为 `WM_USER+1`、`WM_PAINT`、`WM_RBUTTONUP`
  提供自定义分支；左键、键盘和其他消息转给 `DefWindowProcA`。
- `WM_RBUTTONUP` 关闭分支没有调用 `sub_4542CE`，因此没有关闭音效。

本地反编译对照：

- `../rich4/asm/rich4_ui_clicking_top_panel.asm`
- `../rich4/asm/rich4_ui_small_map.asm`
- `../rich4/csrc/fcn_417d65.c`

## 静态图形资源

地图编号统一为 `gmap = stage * 4 + map`，范围 `0..7`。

| 资源 | 子图 | 尺寸 | 用途 |
| --- | ---: | --- | --- |
| `Panel.mkf[1]` | 0 | 439×40 | 顶部工具栏背景 |
| `Panel.mkf[1]` | 6 | 34×32 | “地图”按钮普通态，槽位 `(200,0)-(239,39)` |
| `Panel.mkf[1]` | 17 | 39×37 | “地图”按钮 hover 态 |
| `Map.mkf[16 + gmap]` | 1 | 400×400 | 模态全地图底图，绘制到 `(20,60)-(419,459)` |
| `Data.mkf[517]` | 26/27 | 9×9、11×11 | 两种普通地产归属标记 |
| `Data.mkf[517]` | 28/29 | 17×17、23×23 | 两种设施/公司地产归属标记 |
| `Map.mkf[27 + model_resource_id]` | 6（原版从 1 计数；SDL 零基索引 5） | 随角色资源 | 玩家在全地图上的静态头像 |
| `Data.mkf[0]` | 41 | 随资源 | SDL 软件鼠标指针；模态地图中继续显示和移动 |

V3.11 实际资源扫描结果：

- `Panel.mkf[1]` 是 23 子图 SMP；普通按钮为 `i + 1`，hover 为
  `i + 12`，所以地图按钮索引分别为 6、17。
- `Map.mkf[16..23]` 均为 2 子图 SMP：子图 0 是 200×200 的侧栏
  小地图，子图 1 是本功能使用的 400×400 全地图。
- `Data.mkf[517]` 是 30 子图 SMP，子图 26..29 均真实存在。

### 动态合成规则

- 坐标投影为 `screen = origin + ((11392 * world) >> 16)`，其中
  `origin=(20,60)`。
- 普通地产仅在有业主时绘制，使用
  `Data.mkf[517]` 子图 `26 + (variant & 1)`。
- 设施和公司地产仅在有业主时绘制，使用子图
  `28 + (variant & 1)`。
- 标记图形的每个非零像素都替换为业主角色代表色，不保留原像素色。
- 玩家 `world_x != 0` 时绘制其角色地图资源子图 6；玩家头像覆盖在
  地图和归属标记之上。
- 面板外区域保持打开前的游戏画面，不增加遮罩或边框。

## 动画、语音、音乐与音效资源

| 类别 | 资源/结论 | 说明 |
| --- | --- | --- |
| 动画 | 无 | 不使用 FLC、逐帧 SPR 或计时动画；玩家头像也是固定子图 6 |
| 语音 | 无 | 不访问 `Speaking.mkf`，没有台词或角色语音 |
| 音乐 | 不切换 | 打开期间沿用主地图音乐；没有专用地图音乐 |
| hover 音效 | `Effect.mkf[0]` | 鼠标进入地图按钮槽，且顶部槽索引发生变化时播放 |
| 按下音效 | `Effect.mkf[1]` | 地图按钮左键按下时播放；释放打开时不重复播放 |
| 关闭音效 | 无 | 右键释放直接关闭，不播放取消音或确认音 |

## 可交互 UI 行为

| UI/事件 | 交互行为 | UI/状态变化 | 音效 |
| --- | --- | --- | --- |
| 地图按钮 hover | 指针进入顶部第 6 槽；同槽内移动不重复触发 | 子图 6 切换为 17；离开顶部恢复子图 6 | 首次进入/换槽播放 `Effect.mkf[0]` |
| 地图按钮左键按下 | 记住按钮命令；尚不打开地图 | 保持当前 hover 表现，没有独立 pressed 子图 | `Effect.mkf[1]` |
| 地图按钮左键释放 | 执行已记住的命令；释放点可已移出该槽 | 捕获当前游戏帧并进入全地图模态 UI | 无新增音效 |
| 模态打开 | 初始化 400×400 底图、地产标记和玩家头像 | 主游戏逻辑/动画暂停；以软件鼠标合成前的完整游戏帧为背景，只重绘模态地图和当前鼠标 | 主地图播放列表继续轮换，无音效 |
| 模态内移动鼠标 | 只移动软件指针 | 地图内容无 hover、选中或滚动变化 | 无 |
| 模态内左键按下/释放 | 忽略 | 无变化，不关闭 | 无 |
| 模态内右键按下 | 忽略，等待释放 | 无变化 | 无 |
| 模态内右键释放 | 关闭模态地图 | 清除视图拖动/临时覆盖，调用主地图重绘并恢复正常游戏 | 无 |
| 模态内键盘/手柄 | 原版回调无对应动作；SDL 端消费事件以免泄漏到游戏 | 无变化，不关闭 | 无 |
| SDL 键盘/手柄激活顶部按钮 | 兼容性输入直接执行同一按钮动作 | 打开相同模态地图 | `Effect.mkf[1]` |

全地图没有内部按钮、热区、拖动、缩放、玩家选择、地产选择或镜头
跳转。唯一关闭方式是鼠标右键释放。

## 实现与验证

- `src/platform/sdl1/runtime_main.c`
  - 加载并绘制上述原版资源。
  - 按 ViewModel 中的普通地产、设施、公司和玩家状态合成全地图。
  - 保持按下播放音效、释放打开和右键释放无声关闭的消息时序。
  - 模态期间冻结游戏更新，关闭后恢复主地图视图；背景快照取自软件鼠标
    合成之前，避免把打开瞬间的指针永久烘进背景。
  - `0x4018E7` 的嵌套循环仍分派所有窗口消息；SDL 因此也在模态门控之外
    处理主地图曲目结束，地图保持打开时仍能接续下一首 BGM。
- `src/view/game_view_model.[ch]`
  - 增加公司地产归属投影，渲染器不直接读取 `GameState`。
- `tests/unit/test_game_view_model.c`
  - 覆盖公司股票到公司地产业主的投影。
- `tests/unit/test_renderer_viewmodel_boundary.c`
  - 覆盖全地图渲染器的 ViewModel 边界。
