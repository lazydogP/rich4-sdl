# `0x40AF12` map object reference

- 函数范围：`0x40AF12..0x40B065`，无 callee，12 个直接调用点。
- `0x40AF1B/20`：`id < 2000`，道路表记录宽 40。
- `0x40AF38..44`：严格 `id > 2000 && id < 4000`，地产表索引 `id - 2000`，记录宽 52。
- `0x40AF62..6E`：严格 `id > 4000 && id < 6000`，设施表索引 `id - 4000`，记录宽 56。
- `0x40AF87..93`：严格 `id > 6000 && id < 8000`，股票/事件表索引 `id - 6000`，记录宽 52。
- `0x40AFA5..B1`：严格 `id > 8000 && id < 10000`，特殊对象表索引 `id - 8000`，记录宽 28。
- 因为使用 `jle`/`jge` 排除端点，2000、4000、6000、8000、10000 均不属于相邻表。
- `0x40AFCA` 起处理 `0x8000` 位引用，优先级依次为低 nibble 普通玩家、次低 nibble 特殊玩家、`0x7F00` 路线引用；每类都选最低置位。
- `MapObjectRef` 保留原始 16 位 object ID，并显式返回 kind/index；不解析坐标或访问资源表。
- 置信度：`confirmed`（IDA 反汇编与反编译一致，所有严格边界及三类位引用有单元测试）。
